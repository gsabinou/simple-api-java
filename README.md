# Simple API Java

Aplicação API simples

## Pré-requisitos

- Java 21
- Git
- Docker

## Build e execução

```sh
docker compose up --build
```

## Testes unitários (validação)

./mvnw test


## Documentação online (OpenAPI)

http://localhost:8080/swagger-ui/index.html

![](/assets/images/swagger.png)

## Detalhe sobre o projeto:

Ele foi feito em uma aula durante a FIAP sobre CI/CD. Na aula, tivemos que fazer o deploy da API na Azure, portanto eu enfrentei problemas para criar o banco de dados dela e infelizmente não consegui finalizar esta etapa. Portanto, tudo aqui e na cloud está configurado para funcionar!
